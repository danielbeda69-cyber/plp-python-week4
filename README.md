# Week 4 Assignment: Hands-On Lab - Grades, Eligibility & Smart Decisions

This repository contains my Week 4 Python functions assignment.

## Files

* `welcome.py` - Defines a `welcome()` function that returns a personalized PLP welcome message.
* `toolbox.py` - Contains `double()`, `is_pass()`, and `greet()` functions for practicing parameters, return values, Boolean expressions, and default parameters.

## Reflection

The `greet()` function was the hardest for me to write because it uses a default parameter. I had to understand how Python uses `"Hello"` automatically when no greeting is provided.
